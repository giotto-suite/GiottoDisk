# Create a Giotto Directory Source

Create a `gDirSource` object. See
[gDirSource](https://giotto-suite.github.io/GiottoDisk/reference/gDirSource-class.md)
for more information.

## Usage

``` r
gDirSource(path, ...)
```

## Arguments

- path:

  character. Directory to use as Giotto project backend.

- ...:

  additional params to pass (none implemented)
